# Research paths

Before researching, determine whether the request concerns new information, existing information, or both.

## New-data research

Use the new-data path when the goal is to discover information that is missing from the current topic. The goal is to find new facts and recent developments, discover missing concepts, identify new techniques, alternatives, or use cases, add valuable details and information, and expand the topic without unnecessarily rewriting correct existing content.

For the new-data path:

1. Resolve the target topic.
2. Read the current topic content.
3. Identify missing information.
4. Define focused research questions for the missing information.
5. Search recent and authoritative sources.
6. Filter out information that already exists.
7. Classify genuinely new findings.
8. Decide which existing document should contain each finding.
9. Add relevant information.
10. Create or update diagrams when useful.
11. Update source references and internal links.
12. Validate the result.
13. Report additions, rejected information, and remaining gaps.

## Existing-data research

Use the existing-data path when the relevant information already exists but needs enhancement. The goal is to verify existing claims, improve explanations, refactor unclear structure, remove repetition, correct inaccurate or outdated content, resolve contradictions, improve examples, improve diagrams, references, and links, and replace weak sources with stronger sources.

For the existing-data path:

1. Resolve the target topic.
2. Read the current topic content.
3. Identify unclear, weak, duplicated, outdated, or contradictory sections.
4. Define focused research questions for those sections.
5. Search authoritative sources that verify or challenge the existing content.
6. Compare the sources with the current documents.
7. Refactor explanations and document structure.
8. Correct inaccurate or outdated information.
9. Remove duplicate content.
10. Improve examples and diagrams.
11. Update source references and internal links.
12. Validate the result.
13. Report improvements, corrections, removals, and unresolved issues.

## Combined research

If both missing information and weak existing information are present, use both paths in this order:

1. Read and analyze the existing topic.
2. Run existing-data research.
3. Refactor and improve the current content.
4. Identify information that is still missing.
5. Run new-data research.
6. Add relevant new information.
7. Update diagrams, references, and links.
8. Validate the complete topic.
9. Report improvements and additions separately.

Do not begin with new-data research when the existing content has not yet been inspected.

## Content classification

Classify every meaningful research result as one of:

- new: information not currently present.
- existing-confirmed: existing information confirmed by research.
- existing-corrected: existing information corrected by research.
- existing-expanded: existing information enriched with useful detail.
- existing-refactored: existing information rewritten for clarity or structure.
- duplicate: information already adequately covered.
- irrelevant: information outside the topic scope.
- conflicting: information that disagrees with existing content or other sources.
- uncertain: information that cannot be reliably confirmed.

Do not treat every search result as new content. Add information only when it is relevant, reliable, and useful.
