# Drafts

This folder is the owner's intake space. Every Markdown file here, except this one, is one notion, feedback item, or bug written in the owner's own words. Use subfolders to organize if that helps; they carry no meaning for the workflow.

When the AI takes a draft, it creates a GitHub Issue with the file's content verbatim and the draft's path, then removes the file. From then on the Issue is the record. A draft is taken once, and the AI asks before taking anything.

Specifications, plans, and other workflow artifacts never live here. They live on the Issue or under `docs/`.

The full rule is the Drafts Folder section of the workflow document.
