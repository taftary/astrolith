# References: recommendations

Borrowing rules for a future specification and the owner. Facts in
[research](./research.md); synthesis in [analysis](./analysis.md).

## R-REF-1: borrow narration from Powers of Ten, never pacing

- Keep continuous decade steps with level label plus scale bar plus
  distance always visible [REF-S001].
- Set flight durations from distance and kind per
  [motion](../../motion/documents/README.md); forbid the 10-seconds-per-decade
  film rate as a game rate.

## R-REF-2: borrow tension from Out There, never brutality

- Keep resource survival across distance with deterministic readable
  meters (icon plus number plus bar) and tap-to-travel simplicity
  [REF-S002].
- Tune randomness and loss (permadeath versus rewind, resupply spacing)
  in the gameplay notion with playtesting; do not import roguelike
  severity by default.

## R-REF-3: borrow restraint from Kingdom, never the loop

- Keep one-thumb primary input, single-currency thinking (distance as
  cost), two-tone silhouettes, and near-zero chrome [REF-S003]
  [REF-S004].
- Do not import side view, indirect control, or builder pacing into
  version one; land-and-hold revisits the question in its own milestone.

## R-REF-4: borrow systems thinking from FTL, never panels

- Treat the four meters as ship systems with numbers and states, with
  persistent run state across jumps [REF-S005]; iterate from the one
  feeling and cut the rest [REF-S006].
- Cap persistent HUD at status plus four meters plus one input
  affordance; no multi-panel desktop layout on phones.

## R-REF-5: obey mobile patterns everywhere

- Portrait-first with a separate landscape spec; status top-safe-area;
  input bottom-thumb; 44 to 48 px targets; tabular numerals at or above
  11 pt equivalent [REF-S007] [REF-S008] [REF-S009].

## Validation

- For each borrowed element, name the donor and the excluded remainder
  in the specification; any borrowing without its do-not-take fails
  review.
- Replay the take list after every playtest: if a donor element does not
  serve the one feeling, cut it per the FTL method [REF-S006].
