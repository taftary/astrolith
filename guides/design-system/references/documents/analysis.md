## Synthesis

### Synthesis

The four references converge on one thesis: minimal means carry maximal
state when every element is load-bearing. Powers of Ten proves decade
narration makes vast scale graspable [REF-S001]. Out There proves three
meters plus permadeath tension fit a phone [REF-S002]. Kingdom proves one
input plus silhouettes plus a single currency fit a phone [REF-S003]
[REF-S004]. FTL proves systems-as-UI plus pausable real-time carries
ship survival, and proves desktop density does not fit [REF-S005]
[REF-S006]. Mobile patterns supply the ergonomic frame the four games
assume but rarely state: thumb arc, safe area, orientation variants,
type floors [REF-S007] [REF-S008] [REF-S009].

![Reference map](../images/reference-map.svg)

*Figure 1. Each reference donates one strength; each donates one warning.*

Luminous abstract is the synthesis: Powers of Ten narration plus Out
There tension plus Kingdom restraint plus FTL systems, rendered as glow
and silhouette rather than any donor art style. The draft line naming the
four references plus the current build is therefore a mood board with a
method (follow the feeling, cut the rest [REF-S006]), not a parts list.

## What each reference governs

- Powers of Ten governs [motion](../../motion/documents/README.md)
  narration and the scale bar in
  [HUD](../../hud-and-typography/documents/README.md), never game pacing.
- Out There governs meter tension and event-text feel, never randomness
  tuning or permadeath severity.
- Kingdom governs silhouette economy and chrome restraint across
  [markers](../../markers-and-forms/documents/README.md) and HUD, never
  the game loop.
- FTL governs systems-as-UI thinking for the four meters, never panel
  layout or pause dependence.
- Mobile patterns govern every placement decision in
  [touch](../../touch-and-input/documents/README.md) and HUD.

## Open questions

- No hands-on phone playtest of the cited games was run for this topic;
  takes rest on published descriptions and reviews.
- Event-text voice (Out There lineage) awaits the gameplay notion.
- Whether the land-and-hold phase leans harder on Kingdom is explicitly
  a second milestone, not version one.
