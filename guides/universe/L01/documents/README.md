# L01 — Observable universe

L01 = L1 (ladder row L1, Observable universe, ~93 billion light-years
across). This folder is the L1 visual and lifetime reference (Issue #211):
what the cosmic web looks like, how it was created, how it changed through
time, and how its parts interact — each page with target-visual images and
named sources.

## Scope and scale

L01 covers the whole observable volume: diameter ~93 billion light-years
(~8.8 x 10^26 m, ~10^27 m rung), age 13.787 +/- 0.020 Gyr (Planck 2018).
It is the top of the [Universe ladder](../../documents/README.md#levels):
step down to [L02 — Cosmic web](../L02/documents/README.md) for the
filament/wall/void detail below this whole-view level. Frozen scale rules
live in `docs/universes/ladder.md`; this folder holds the descriptive
reference only.

## Whole view

- [cosmic-web.md](./cosmic-web.md) — the whole: creation from inflation seeds,
  evolution to today, part interactions, key numbers, image credits.
  Start here.
- [lifetime.md](./lifetime.md) — the full dated timeline: Big Bang to present
  plus far-future fate, with alternates on the record. The dated spine the
  whole-view and part docs hang events off.

Read order: whole (`cosmic-web.md`) first, then any part below, then the
dated spine (`lifetime.md`) for dates behind each claim.

## Parts

- [Voids](./voids.md) — underdense expanses: looks, growth and merging, creation,
  outflows and probes, Local/Bootes/KBC/Eridanus examples.
- [Filaments](./filaments.md) — threads and bridges: observed gas bridges, Zel'dovich
  creation, mass growth, cluster feeding, Sloan/Quipu/Coma examples.
- [Walls](./walls.md) — sheets and pancakes: edge-on vs face-on views, draining into
  filaments, CfA2/Sloan/South Pole walls, Dipole Repeller context.
- [Nodes](./nodes.md) — clusters at filament intersections: ICM, brightest galaxies,
  lensing, hierarchical assembly, Virgo/Coma/Bullet/El Gordo.
- [Superclusters](./superclusters.md) — largest complexes: basins of attraction, Laniakea
  home, Shapley pull, future dispersal, Quipu/Hyperion extremes.
- [Background](./background.md) — the setting: CMB, expansion, dark matter scaffolding,
  dark energy, and the probes that measured each.
