# L02 — Cosmic web

L02 = L2 (ladder row L2, Cosmic web, 10^24–10^26 m). This folder is the L2
visual and lifetime reference (Issue #219): what its parts look like, how
they were created, how they changed through time, and how they interact —
each page with target-visual images and named sources.

## Scope and scale

L02 covers one cell of cosmic-web geography: filaments, walls, giant voids
and supercluster basins in the tens-to-hundreds of Mpc range, anchored on
the Sloan Great Wall (1.37 billion light-years, 1.30 x 10^25 m). It sits
between the whole-view [L01 — Observable universe](../../L01/documents/README.md)
above and [L03 — Galaxy clusters and groups](../../L03/documents/README.md)
below, under the [Universe](../../documents/README.md#levels) ladder.
Frozen scale rules live in `docs/universes/ladder.md`; this folder holds
the descriptive reference only.

Read order: bridge ([previous-l1.md](./previous-l1.md)) first, then the entry transition
([entry.md](./entry.md)), then any part below, then the dated spine ([lifetime.md](./lifetime.md))
for dates behind each claim.

## Figures at a glance

Canonical detail lives in the linked pages; this index carries only the
navigation-level numbers: L2 span 10^24–10^26 m; anchor Sloan Great Wall
1.37 Gly (1.30 x 10^25 m); homogeneity scale ~70–80 Mpc/h (smooth above,
structured inside); Laniakea home basin ~500 Mly / ~160 Mpc (~100,000
galaxies); BAO ruler ~150 Mpc; filaments typically 50–80 Mpc long and
~1–2 Mpc wide; voids 20–100+ Mpc across; L1-to-L2 ratio 1.48e-2 with
8 octant portals per L1 cell — see [key numbers](./previous-l1.md#key-numbers),
[entry numbers](./entry.md#key-numbers), and the
[dated timeline](./lifetime.md).

## How this level differs from L01

[L01](../../L01/documents/README.md) shows the whole observable volume as one
smooth ball with the web below resolution; here the web is the subject —
topology of dense complexes, threads, sheets and dark gaps inside a single
L2 cell. The L01 companion pages ([Filaments](../../L01/documents/filaments.md),
[Walls](../../L01/documents/walls.md), [Voids](../../L01/documents/voids.md),
[Superclusters](../../L01/documents/superclusters.md)) give the whole-view
context; the pages above give the L02-scale detail (tens-to-hundreds of Mpc
threads, named walls and voids, flow basins). The map is surveyed, not
simulated — SDSS/BOSS proved the ~150 Mpc ruler, DESI (five-year survey
completed April 2026) and Euclid (first data March 2025) are redrawing it —
so new superstructures (South Pole Wall 2020, Quipu 2025) enter through the
part docs, not this index.
