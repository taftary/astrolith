# L01 — Observable universe

L01 = L1 (ladder row L1, Observable universe, ~93 billion light-years
across). This folder is the L1 visual and lifetime reference (Issue #211):
what the cosmic web looks like, how it was created, how it changed through
time, and how its parts interact — each page with target-visual images and
named sources.

## Whole view

- `cosmic-web.md` — the whole: creation from inflation seeds, evolution to
  today, part interactions, key numbers, image credits.
- `lifetime.md` — the full dated timeline: Big Bang to present plus
  far-future fate, with alternates on the record.

## Parts

- `voids.md` — underdense expanses: looks, growth and merging, creation,
  outflows and probes, Local/Bootes/KBC/Eridanus examples.
- `filaments.md` — threads and bridges: observed gas bridges, Zel'dovich
  creation, mass growth, cluster feeding, Sloan/Quipu/Coma examples.
- `walls.md` — sheets and pancakes: edge-on vs face-on views, draining into
  filaments, CfA2/Sloan/South Pole walls, Dipole Repeller context.
- `nodes.md` — clusters at filament intersections: ICM, brightest galaxies,
  lensing, hierarchical assembly, Virgo/Coma/Bullet/El Gordo.
- `superclusters.md` — largest complexes: basins of attraction, Laniakea
  home, Shapley pull, future dispersal, Quipu/Hyperion extremes.
- `background.md` — the setting: CMB, expansion, dark matter scaffolding,
  dark energy, and the probes that measured each.

## Target visuals

`images/` holds the reference images, each with source, credit and license in
its doc. Simulation backbone (`tng300`, `millennium`), observed tracers
(`sdss-pie2`, `nasa-svs-sdss-journey3`), origins (`planck-cmb-2013`),
total-matter view (`planck-lensing-matter-map`), plus per-part close-ups
(filament bridge, void galaxy, wall maps, cluster composites, Laniakea
context, expansion timeline).
