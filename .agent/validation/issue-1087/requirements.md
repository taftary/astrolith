# Requirements — Issue #1087

- [ ] C1: Access: the original route denial has a documented cause or documented external resolution, and the independent validator successfully executes an authorized release no-picture route. Any required rule change has an exact owner-confirmed scope. If access remains denied, this criterion is unmet. (judged by the validator from preflight evidence and docs/validator-capabilities.md; no script probe)
- [ ] C2: Reproducibility: the runner, recorded environment, fixed configurations and fixture identities support repeating a run without relying on the owner's saved settings. Absent information and non-equivalent runs are explicitly classified. (judged by the validator from scripts/validation/profile_run.py and .agent/validation/issue-1087/evidence/; no script probe)
- [ ] C3: Timing/loading: live runs produce raw intervals, separate main/render CPU measures, defined observable waits, effective quality/resolution, terrain budgets and readiness completion status. Summary tests cover warm-up separation, percentiles, stalls and incomplete loading. Missing readings are never fabricated as zero. (judged by the validator from runtime evidence and timing tests; no script probe)
- [ ] C4: Memory/resources: a real app run produces timestamped one-second working-set observations and correctly scoped live mesh/material/image counts over ten scene/quality transitions. The report documents sampling gaps, caches, limitations and any observed growth. (judged by the validator from .agent/validation/issue-1087/evidence/; no script probe)
- [ ] C5: Fixtures/duration: executable fixtures cover all specified scenes/configurations. Demonstrate at least one full short run in each fixed configuration and one 21-minute warm-up-plus-sustained run; verify ten scored scenario blocks and raw frame coverage. Main-agent checks demonstrate second-world, selection, night and first-person starting states. (judged by the validator from fixtures and runtime/visual evidence; no script probe)
- [ ] C6: Isolation: disposable normal-launch save/restart/Reset works through real application behavior. The real player's settings presence/hash is unchanged, normal startup remains unchanged, and profiling output/sampling is absent when not requested. (judged by the validator from isolated settings evidence and runtime collector registration; no script probe)
- [ ] C7: Failure behavior/overhead: malformed fixtures, unavailable required sampling, process failure, and timeouts are reported distinctly with non-success results and preserved partial evidence. No leftover child app remains after managed timeout. Three matched alternating collection-on/off pairs disclose overhead. (judged by the validator from real child tests and .agent/validation/issue-1087/evidence/; no script probe)
- [ ] C8: Handoff: repeat instructions, raw proof evidence, schemas/units, optional GPU result and independently proven capability registry entries are delivered. The independent #1085 preflight is rerun against these capabilities and its actual verdict is recorded; no success is inferred from compilation or source inspection. (judged by the validator from documentation, evidence and #1085 preflight comment; no script probe)
- [ ] C9: Follow the short-run instruction on the reference PC. Expect a real window, automatic completion, and readable timing/loading/memory/resource reports identifying the configuration and build. (judged by the validator from the documented command and actual short-run outputs; no script probe)
- [ ] C10: Review the listed scenes and second-world/first-person/night samples supplied by the main agent. Expect reproducible, distinct starting states suitable for the later comparison. (judged by the validator from main-agent scene evidence; no script probe)
- [ ] C11: Run the disposable settings check, change a graphics choice, restart and Reset. Expect changes confined to the disposable profile; opening your ordinary game retains your original preferences. (judged by the validator from settings interaction and profile-hash evidence; no script probe)
- [ ] C12: Review the sustained and ten-transition reports. Expect complete scored durations, explicit stalls/incomplete loads, sampling limitations and observed resource growth, rather than a claim that the renderer has been optimized. (judged by the validator from sustained and transition raw evidence; no script probe)
- [ ] C13: Review the independent validator evidence. Expect an authorized no-picture run and a clear #1085 preflight result; any remaining access or measurement gap stays visible. (judged by the validator from independent preflight records, not final CI or PR verdict observations; no script probe)
